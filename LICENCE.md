## 🧩 About

**GTFO Config** is a comprehensive configuration tool for GTFO featuring HUD customization, loot tracker, enemy radar, damage indicators, quick loadout presets, and performance tweaks.

Based on popular mods like **GTFO Mod Menu**, **Config Manager**, and **QOLMod**.

---

## ✨ Features

### 🎮 Core Config
- HUD Customizer — reposition and resize health, ammo, and objective widgets
- Loot Tracker — highlight nearby resources and consumables
- Enemy Radar — display nearby enemy positions on a minimap
- Damage Indicators — show floating damage numbers
- Quick Loadout — save and load weapon/gear presets

### 🎨 Visuals & Interface
- Crosshair Editor — customize crosshair style, color, and size
- FPS Boost — disable unnecessary effects for higher frame rates
- Colorblind Modes — alternative color schemes for accessibility
- Streamer Mode — hide sensitive information for streaming

### 🏋️ Utility & Automation
- Auto-Pickup — automatically collect nearby items
- Quick Swap — bind keys for instant weapon switching
- Config Profiles — switch between different setting sets
- Backup & Restore — save and load configurations

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"F1"` | Toggle config menu |
| `process_name` | String | `"GTFO.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Restrict risky features |
